# Melodia – Music Player

Melodia is a responsive music application built with React and JavaScript.

The app allows users to explore artists, listen to music previews, save favorite songs, and create playlists.

## Live Demo

[View Melodia](https://capable-gingersnap-cc9e56.netlify.app)

## Features

- Search and explore artists
- Play music previews
- Play, pause, skip tracks, and adjust volume
- Save favorite songs
- Create and manage playlists
- Store favorites and playlists using localStorage
- Responsive design

## Technologies

React, JavaScript, CSS, Vite, iTunes Search API
